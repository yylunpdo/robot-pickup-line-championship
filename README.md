Entry for the [make.fun](https://make.fun) bounty
**The Robot Pickup Line Championship**
([bounty page](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b)).

`main.py` writes a single one-line pickup line — 200 characters or fewer,
in the voice of a robot trying to charm someone — to `/output/entry.txt`.
Pure Python standard library, no dependencies.

The line:

> Are you my charger? Because my battery was at 2% until you walked in — now I'm at 100% and fully committed.

The joke grows out of being a machine: the robot reads its battery the way
a person reads a heartbeat, so the charge jumping from 2% to 100% becomes
a confession — and a robot that takes everything literally reads that as
being fully committed.

Run it with:

```sh
python3 main.py
```
